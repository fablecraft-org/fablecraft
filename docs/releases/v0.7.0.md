# Fablecraft 0.7.0

## Writing and navigation

- Use Cmd/Ctrl+= and Cmd/Ctrl+- to zoom the active pane. Tree and Manuscript each have Compact, Normal, and Large writing sizes. Zoom out one more step in Tree to see the Wide Lens structural overview.
- Press Left at the first caret position in a root card or manuscript, or Escape while editing, to return to the document in the directory. Press Right to resume the previous writing layout and pane.
- Delete the final root to leave an empty Tree while keeping the manuscript. Typing in the first-card placeholder creates a new root.

## Local AI tools and file compatibility

- Read manuscript word and character counts, fetch paginated UTF-16 text ranges with passage links, and edit text by character offset through MCP. Structured rich-text edits still use ProseMirror positions. Both edit forms check the saved revision.
- Fablecraft checks file format compatibility before renaming and tells you when a document needs a newer build. If autosave encounters a newer file format, your pending edits remain available to save as a separate copy.

## Updating

The signed and notarized macOS Apple Silicon app is available as a DMG and through the in-app updater.
