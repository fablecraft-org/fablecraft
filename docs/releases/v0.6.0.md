# Fablecraft 0.6.0

## Manuscript

- Write a continuous manuscript alongside the idea tree. Use the Window menu or command palette to show Tree, Manuscript, or both in a resizable split.
- Link selected prose to a card with Control+L, or type a card ID such as `#B02` to link a paragraph. Linked passages appear in the manuscript margin and in the card’s backlinks.
- Search, import, and export the manuscript independently of the tree. Undo follows edits across both panes and preserves passage links.
- Read the manuscript and edit rich-text ranges through the local MCP server. Revision checks preserve pending work when another writer saves first.

## History

- Browse retained autosaves in the History panel. Press Cmd+Shift+H on Mac or Ctrl+H on Windows and Linux. Use the arrow keys to browse and Enter to navigate a read-only snapshot.
- See which cards were added, edited, moved, or deleted, along with character totals. History opens affected sections in the Tree or Manuscript and highlights added text.
- Copy prose or a subtree from an earlier version. To edit an older snapshot, press Enter from its Tree or Manuscript and confirm the restore. History records the restore as a new latest save and keeps the intervening revisions.
- The first page and its diffs are preloaded. Low-value saves within editing bursts are pruned on save, and the archive thins progressively as snapshots age.

## Tree and navigation

- Use **New Document From Tree** to move a subtree into a new document while preserving its hierarchy and order.
- Use Tab+Arrow to create cards. Tab+Left wraps the current level in a parent. In navigation mode, Cmd/Ctrl+Up or Down jumps to the first or last sibling, and Cmd/Ctrl+Left jumps to the branch root.
- Tree navigation animates card positions over 150 ms and respects the system Reduce Motion setting.

## Updating

The signed and notarized macOS Apple Silicon app is available as a DMG and through the in-app updater. Existing documents upgrade when opened. Earlier Fablecraft versions may reject a file after its schema has been upgraded.
