# Fablecraft 0.5.0

- Cards adapt to the window with one to four columns, consistent gaps, and automatic widths. Long cards start at the top of the window; editing reveals the caret without jumping to the bottom.
- Choose Wide Lens, Normal, or Focused from the command palette or Window menu. Command/Control + and − step between the three views.
- Wide Lens shows the tree with compact card previews, soft shadows, darker selected-card shadows and path lines, and no child-count badges.
- Focused provides a wider writing column, with only the active card and siblings sharing its parent. Subtle chevrons indicate available navigation directions.
- Child groups use available vertical space while preserving the visible path to the last visited child. Returning through the tree keeps the remembered child in view.
- Link to another card by typing its moniker, such as #B08, followed by Space, or by pasting a copied card into the editor. Links retain the target's identity when cards move or are reordered.
- Inline links also expose reference children, with path-aware navigation and bounded expansion of circular references. References preserve the original ownership of cards.
- Create passage-anchored children from selected text, and use Tab + Arrow to create cards directly while editing.
- Improve parent-aligned layout, root-card indentation, rich-text splitting, empty-card subtree paste, and return navigation after deleting or abandoning a card.

The macOS Apple Silicon download includes the signed and notarized desktop app. Existing installations can update through the in-app updater.
