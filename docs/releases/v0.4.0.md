# Fablecraft 0.4.0

- The document title stays centered above the writing canvas. Cards fade behind it as you pan.
- Press Left from a root card to browse files and folders in a separate view. Arrow keys select entries without a second focus highlight.
- Use Ctrl or Command with Right, Up, or Down in the directory to create a document. The new file starts with its name selected for editing. Enter confirms the name, Escape keeps the generated name, and Right opens the file.
