# Fablecraft 0.3.0

## Writing

- New cards start with normal paragraph text. Use Markdown heading markers such as `# `, `## `, or `### ` when you want a heading.
- Dividing existing text with three Enters moves the lower section into a new card, preserves its formatting, and keeps the cursor active at the start of that section.
- Cards shrink to fit their current content after text is removed or split, eliminating excess space caused by stale height estimates.
- Pasting onto an occupied card creates a sibling below it and preserves rich formatting. Empty leaf cards are filled in place.
- Convert Card to Document moves a selected card and its descendants into a new `.fable` document.

## Navigation and reliability

- Left/Right retraces the last visited path through cards, folders, and documents. Moving vertically resets that return path.
- Folder navigation includes neighboring folders and documents, and hides dot-prefixed folders.
- Open Recent checks every saved path and removes missing files before displaying the list.
- Document deletion moves files to recoverable system Trash. On macOS, Finder is used as a fallback if the native operation fails; errors retain diagnostic details.
- Trashing the current document clears its cached contents and history. Trashing another document leaves the current one open, and delayed saves cannot recreate a trashed file.
- Dismissing the beta notice persists across windows and app restarts.
- Settings show exactly one active row chevron.

## Distribution

The macOS Apple Silicon installer and signed automatic-update artifacts are published with this release. Existing headings and document content are preserved.
